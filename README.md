# 🃏 Triple Triad - HTML, CSS & JavaScript

¡Bienvenido a **Triple Triad**, una recreación moderna del legendario minijuego de cartas de **Final Fantasy VIII**! Este proyecto está desarrollado exclusivamente con tecnologías web nativas (**HTML5, CSS3 y JavaScript Vanilla**), sin frameworks ni librerías externas.

Desafía tu mente en un tablero de **3x3** donde la estrategia, el posicionamiento y el cálculo matemático lo son todo.

---

## 🚀 Características del Proyecto

- 🎮 **Jugabilidad Clásica:** Mecánica pura de Triple Triad (coloca cartas y captura las adyacentes si tu número es mayor).
- 🧠 **Modos de Juego:** 
  - 👥 Local de 2 Jugadores (en la misma pantalla).
- 🎨 **Estética Cuidada:** Diseño limpio con marcos inspirados en el juego original y paletas de colores suaves (Azul 🔵 vs Rojo 🔴) para identificar los equipos.
- ⚡ **Animaciones Fluidas:** Transiciones con CSS para el volteo de las cartas al ser capturadas.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica del tablero y la interfaz.
- **CSS3 (Grid & Flexbox):** Maquetación responsiva, posicionamiento de las cartas y efectos visuales.
- **JavaScript (ES6+):** Lógica del juego, control de turnos, matriz del tablero y reglas de captura numérica.

---

## ⚙️ Reglas Planificadas / En Implementación

Además de la regla básica de captura por valor numérico, el objetivo es incluir las famosas reglas adicionales:

- [x] **Regla Básica:** Captura por número mayor.
- [ ] **Igual (Same):** Captura múltiple si los valores coinciden exactamente.
- [ ] **Suma (Plus):** Estrategia matemática sumando los lados de las cartas.
- [ ] **Combo (Cadena):** Reacciones en cadena tras una captura especial.
- [ ] **Elemento:** Modificadores (+1/-1) según la casilla del tablero.

## 📦 Instalación y Uso Local

¡No necesitas instalar dependencias de Node ni configurar servidores! Para probar el juego en tu ordenador:

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com
   ```
2. **Entra en la carpeta del proyecto:**
   ```bash
   cd Reto1
   ```
3. **Abre el archivo principal:**
   Simplemente haz doble clic en el archivo `index.html` en tu navegador favorito, ¡y a jugar!
